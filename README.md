# Castex

**Castex** (Cast + Next-Gen) is a free, open-source, ad-free, cross-platform media streaming player and entertainment ecosystem built for Android Mobile, Android TV/Firestick, iOS, macOS, and Web.

## Key Highlights
- **3-Layer Hybrid Dub Router:** 1-click switching between Original Audio, Official Dubs, and Verified Community Fandubs.
- **KotoSub AI Engine:** Zero-delay in-stream subtitle extraction and real-time translation (Hinglish, Bangla, Banglish, and global languages).
- **Modular URL/JSON Plugins:** Supports Stremio addons (`manifest.json`) and remote JSON catalogs without any central media hosting.
- **4 Editions:** Stable, Beta, Advance (Pro Fork), and Lite (8-12 MB).

## Legal & DMCA Disclaimer
Castex is strictly a media player and metadata/addon client. **Castex does not host, upload, store, or distribute any copyrighted video, audio, or media files on any server.** All streams and subtitles are loaded dynamically from user-configured third-party Stremio addons, official public embeds (such as YouTube), or remote JSON manifests. Users are solely responsible for ensuring they have the legal right to access any content they stream through third-party addons.
